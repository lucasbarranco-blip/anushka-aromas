Conectar con GitHub

Para que "Publicar" actualice el catálogo online, necesitás un token de acceso de GitHub (se guarda solo en este navegador). Se hace una sola vez.

  1. Entrá a github.com/settings/tokens (Fine-grained) → Generate new token.
  2. Repository access → Only select repositories → anushka-aromas.
  3. Permissions → Repository → Contents → Read and write.
  4. Generá, copiá y pegá el token abajo.

Agregar producto

Se agrega a la lista de cambios. Recordá tocar Publicar cambios para que aparezca online.
